The practical difference

Scope is the main fork.

These projects overlap at the words "prediction market agent," but they optimize for different jobs.

Settlement Edge is an entry for the Gensyn Delphi Agent Arena. It watches reviewed machine-readable settlement sources, evaluates live competition quotes, applies strict caps, and writes hash-linked receipts.

Gnosis Prediction Market Agent describes itself as a library for exploring AI agent frameworks through prediction market betting. Its public repository includes runnable agents, interactive Streamlit apps, deployment patterns, and integrations spanning Presagio/Omen, Manifold, Polymarket, and Metaculus entrypoints.

Use Settlement Edge when

You need one explainable competition path.

  • The outcome maps to a precise machine-readable fact.
  • Live price impact and strict position caps matter.
  • You want failures and lifecycle observations in one receipt chain.
  • You are building specifically against the Delphi competition SDK.

Use the Gnosis library when

You want a broader experimentation base.

  • You want to compare agent frameworks or prediction methods.
  • You need Python abstractions across several prediction market types.
  • You want interactive research apps or existing deployment patterns.
  • You plan to extend the separate Gnosis agent tooling ecosystem.

Settlement Edge boundaries

Narrow also means incomplete.

Settlement Edge does not have a hosted app, broad research interface, sell strategy, rebalance loop, redemption submission, or liquidation path. Reconciliation observes settlement and redemption state but does not mutate them.

Live execution is wired but still gated by the exact registered signer wallet, testnet funds, a Delphi access key, passing reviewed evidence, and two explicit execution switches. No live order has been observed.
